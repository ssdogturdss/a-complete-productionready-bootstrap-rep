# AI Admin Agent

Production-ready AI-powered server administration and deployment agent.

## Quick Install (Recommended)

```bash
curl -fsSL https://raw.githubusercontent.com/<USERNAME>/ai-admin-agent/main/install.sh | bash
```

## Manual Install

```bash
git clone https://github.com/<USERNAME>/ai-admin-agent.git
cd ai-admin-agent
./install.sh
```

See full documentation in docs/ARCHITECTURE.md and the wizard for configuration.

## Features
- Natural language commands for GitHub and server ops
- Automated deployments to GitHub Pages or local server with Caddy HTTPS
- Docker + systemd management
- Persistent memory and conversation history
- Strong safety defaults
